# 岔路

有些路只能走一次。在这里，两条路你都走。

写下一个决策难题，游戏找到最接近的内置岔路，让你同时走两条路，一年一年过。走完后把同样的规则各跑一千遍，告诉你：只走一遍就下结论，有多大概率看反。

## 和《八十亿分之一》一样：运行时不调用模型

岔路不是一个个写死的，而是由六个维度拼出来的：去处、位置、城市、离家远近、感情、存款。规则挂在属性上，不挂在题目上，就像《八十亿分之一》按国家查表。每条路 540 种拼法，一共能拼出 145,530 种岔路。玩家写下的难题在浏览器本地读成两组属性，所有模拟都在浏览器里算，不需要密钥，也不需要服务器。

另有六个精修的岔路（大厂/中厂、辞职单干、读博、回老家、考公、异地），事件逐句手写。

在线试玩：开启 GitHub Pages（main 分支 /docs 目录）后访问 https://salt-byte.github.io/chalu/

内置的都不像时，可以在页面里填自己的 DeepSeek 密钥，让模型现场拆。密钥只留在浏览器内存里。

## 本地运行

```
npm run build
DEEPSEEK_API_KEY=你的密钥 npm start
```

打开 http://localhost:3000 。不配密钥也能玩内置的两个难题。

默认用 DeepSeek（模型名 `deepseek-flash`，可用 `CHALU_MODEL` 改）。要换成 Claude：`CHALU_PROVIDER=anthropic ANTHROPIC_API_KEY=...`。

## 结构

- `src/engine.js` 模拟引擎、已核实的规律库、内置难题。页面和服务端共用。
- `src/compose.js` 拼装器：六个维度、每个属性带来的事件和规则、从一句话里读出两条路。
- `src/stage3d.js` 三维舞台（three.js，已随仓库打包，不依赖外网）。
- `src/game.js` `src/game.css` `src/body.html` 游戏界面。
- `server.js` 发页面，并代玩家向 Claude 要一个「岔路包」。密钥只在服务端。
- `build.js` 把 src 拼成 `dist/index.html`。

## 三条不变的规矩

1. 模型只能按编号引用规律库里的规律。库外的一律标「未核实」，不显示出处。
2. 类比（兵法、古语）只出现在解说里，不改任何数字。
3. 所有概率都是设定的，最影响结果的几个可以在揭晓页直接改。
